# Telegram Mini App "Бросай"

Счетчик дней для Telegram с точным дизайном по макету.

## Особенности

- ✅ **Точные цвета**: `#2FA753`, `#589547`, `#C14141`, `#FFFFFF`
- ✅ **Шрифты**: Holtwood One SC (200px) для цифр, Days One (150px) для "дней"
- ✅ **Функционал**: Зеленая кнопка +1 день, красная ничего не делает
- ✅ **Telegram интеграция**: WebApp SDK, вибрация, убираем стандартные кнопки
- ✅ **Адаптивность**: Равное разделение экрана пополам
- ✅ **UX**: Анимации нажатия, отключение выделения текста

## Установка

```bash
# Клонировать репозиторий
git clone <your-repo>
cd telegram-mini-app

# Установить зависимости
npm install

# Запустить в режиме разработки
npm run dev
```

## Настройка в BotFather

1. Откройте [@BotFather](https://t.me/BotFather)
2. `/newapp` → выберите вашего бота
3. Название: "Бросай"
4. Описание: "Счетчик дней"
5. Web App URL: `https://yourdomain.com`
6. Upload icon (опционально)

## Деплой

### Vercel (рекомендуется)

1. Подключите репозиторий к Vercel
2. Настройте домен
3. Укажите URL в BotFather

### Netlify

1. Подключите репозиторий к Netlify
2. Настройте домен
3. Укажите URL в BotFather

### Собственный сервер

```bash

```

## Технические детали

- **Framework**: Next.js 14 с App Router
- **Styling**: Tailwind CSS
- **Telegram SDK**: telegram-web-app
- **TypeScript**: Полная типизация
- **Fonts**: Google Fonts (Holtwood One SC, Days One)

## Функционал

- Счетчик дней с увеличением на +1 при нажатии зеленой кнопки
- Красная кнопка не изменяет счетчик (по требованию)
- Вибрация при нажатии кнопок
- Анимация масштабирования кнопок
- Отключение выделения текста
- Адаптивный дизайн для всех устройств

## Цветовая схема

- Верхняя панель: `#2FA753` (зеленый)
- Нижняя панель: `#FFFFFF` (белый)
- Зеленая кнопка: `#589547`
- Красная кнопка: `#C14141`
- Текст/иконки: `#FFFFFF` (белый)
